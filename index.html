Obsidian × Google Drive

Personal Technical Project

A personal technical project documenting the configuration of bidirectional synchronization between Obsidian on Windows and iPad using Google Drive.

1. Project Overview

The purpose of this project is to establish a convenient cross-device synchronization workflow for Obsidian notes. Google Drive is used as the cloud storage platform, while the GSync community plugin is used to manage file synchronization.

2. System Architecture

  • Windows PC running Obsidian
  • iPad running Obsidian
  • GSync community plugin
  • Google Drive cloud storage
  • Google Drive API and OAuth 2.0 authentication

3. Technical Configuration

The synchronization environment requires a Google Cloud project, an enabled Google Drive API, OAuth 2.0 credentials, and the configuration of the GSync plugin on both devices.

GitHub Pages is used to host the project documentation and OAuth callback page.

4. Synchronization Workflow

Windows to iPad:

Changes made in the Windows Obsidian vault are synchronized through Google Drive and become available on the iPad.

iPad to Windows:

Changes made on the iPad are synchronized through Google Drive and become available on the Windows computer.

5. Privacy and Security

Google OAuth is used for account authorization. Synchronization data is stored in the user's own Google Drive account. Users should review the permissions requested by the plugin before granting access.
